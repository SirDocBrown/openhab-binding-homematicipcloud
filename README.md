# openhab-binding-homematicipcloud
Community-Binding für openHAB zur direkten Anbindung von Homematic IP über den Access Point und die Homematic-IP-Cloud. Erkennt Geräte und Gruppen, meldet Fenster- und Batteriestatus und steuert Rollläden, Licht und Heizung. Mit installierbarer JAR und deutscher Anleitung. Getestet mit HmIP-HAP2 und HmIP-SWDM
